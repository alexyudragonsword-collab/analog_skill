Analog Studio 用户手册

Analog Studio 是一个模拟集成电路设计与仿真工作台,基于 ngspice 仿真器与 PTM(Predictive Technology Model)工艺模型,提供三大功能:gm/ID 设计器、ngspice 教学案例、特性曲线浏览器。

1. 准备工作:安装 ngspice

本软件依赖系统中的 ngspice 仿真器,请先安装:

  • Windows:从 ngspice.sourceforge.io 下载 zip 包,将其中的 Spice64/ 文件夹解压到本程序 exe 同级目录(免配置);或解压到任意位置后在 设置 中指定 ngspice.exe 的路径
  • Linux:sudo apt install ngspice
  • macOS:brew install ngspice

启动后请查看窗口右下角状态栏:

  • ngspice ✓ 绿色 —— 检测成功,一切就绪
  • ngspice ✗ 红色 —— 未找到,窗口顶部会出现红色横幅, 仿真按钮被禁用。点击状态栏指示器或横幅上的 Locate… 按钮打开设置, 手动指定 ngspice 路径

2. gm/ID 设计器(第一个标签页)

基于 gm/ID 方法学的晶体管尺寸设计工具:以跨导效率 gm/ID 为核心变量, 用仿真生成的查找表(而非长沟道公式)完成精确的尺寸计算。

2.1 构建查找表

  1. 在 Lookup table 区域选择工艺模型(nmos180 / pmos180 / nmos45hp / pmos45hp / nmos22hp / pmos22hp,下拉框中标注了各自的 VDD)
  2. 设置参考宽度 W(结果与 W 无关,默认 10 um 即可)、沟长 L、漏源电压 Vds(勾选 auto 则自动取 VDD/2)
  3. 点击 Build / Load Table。首次构建需要运行 ngspice 扫描 (约几秒到几十秒,进度显示在底部日志面板);结果自动缓存, 之后相同参数瞬间加载(日志中显示 [cache])

构建完成后,按钮下方显示该表的有效范围:gm/ID 区间、fT 最大值、gm·ro@15。 右侧同时画出四张设计曲线:fT、Id/W(对数轴)、gm·ro、Vgs 与 Vov, 横轴均为 gm/ID。

2.2 计算工作点(sizing)

在 Sizing 区域选择三种模式之一:

  • Size by gm/ID:指定 gm/ID 值,再固定 Id、W、gm 三者之一,求其余参数。 例:gm/ID=15、Id=100uA → 求得 W ≈ 10 um
  • Size for fT ≥ target:给定 fT 下限,自动选择满足条件的 最高 gm/ID(即功耗最低的工作点)。适合带宽约束的场景
  • Size for gm·ro ≥ target:给定本征增益下限,同样自动选最省电的点。 适合高增益级

点击 Compute Operating Point,结果以工程单位显示在左下角表格中 (W、Id、gm、Vgs、Vov、fT、gm·ro、Id/W),并在右侧四张曲线上以 红色虚线 + 圆点标记该工作点。 Copy as text 可将结果复制到剪贴板。

若目标超出该表能力范围(如 fT 目标高于最大值),错误信息会以红字提示, 不会中断程序。

3. ngspice 教学案例(第二个标签页)

内置 9 个标准 SPICE 教学案例,覆盖直流、交流、瞬态与噪声四类分析:

  1. Tran — RC 充电(电压与电流)
  2. DC — NMOS Id-Vds 特性曲线族
  3. AC/Noise — RC 低通滤波器频响与输出噪声
  4. Tran — 采样保持开关对比(真实 NMOS vs 理想开关)
  5. Tran — kT/C 噪声时域统计(直方图 + 高斯拟合)
  6. DC — NMOS 电流镜输出特性
  7. AC — 共源放大器 Bode 图
  8. DC — 传输门导通电阻(180/45/22nm 三节点对比)

使用方法:左侧列表选择案例 → 中部表单调整参数(电阻、电容、管子尺寸、 偏置电压等,Reset defaults 恢复默认)→ 点击 Run simulation。 仿真在后台运行,进度实时显示在日志面板,完成后右侧显示结果图。

结果图支持滚轮缩放、拖拽平移;Fit 恢复适应窗口, Save as… 另存 PNG,Open folder 打开输出目录。

4. 特性曲线浏览器(第三个标签页)

为任意工艺模型生成标准特性图,用于工艺对比与设计前的器件评估:

  • gm/ID four-quadrant:四象限特性图 —— gm/ID vs Vov(含 BJT 极限与 2/Vov 渐近线)、Id/W vs gm/ID、fT vs gm/ID、gm·ro vs gm/ID, 多条 Vds 曲线叠加
  • IV characteristics:IV 特性 —— 线性/对数坐标的 Id-Vov、 Id-Vgs 全扫描、Id-Vds 输出特性曲线族
  • Gate capacitances:栅电容 —— Cgg/Cgs/Cgd/Cgb vs Vgs (解析模型,速度快)

选择模型、图类型、W、L 后点击 Generate / Show。同参数的图会在会话内缓存, 再次查看瞬间加载;Regenerate 强制重新仿真。

5. 日志面板与任务队列

窗口底部的 Simulation log 面板实时显示所有仿真进度与 ngspice 输出, 出错时附带错误详情和最新日志文件的末尾内容。该面板可拖到窗口右侧或独立浮动。

所有仿真任务经由单一后台队列串行执行:同时发起多个任务时会依次排队, 界面始终保持响应,状态栏左侧显示当前正在运行的任务。

6. 常见问题

现象处理
顶部红色横幅"ngspice not found" 安装 ngspice(见第 1 节),或点击 Locate… 手动指定路径
构建查找表很慢 首次构建需运行完整扫描属正常;相同参数第二次起走缓存,秒级完成
Sizing 报红字错误 目标超出该模型/沟长的能力范围;增大 L(提升 gm·ro)或放宽目标
仿真失败 查看日志面板中的错误详情;常见原因是模型文件缺失或参数超出合理范围


输出文件位置:开发模式下在各工具目录的 plots/ 与 logs/;打包版在用户数据目录的 AnalogStudio/workspace/ 下, 安装目录不会被写入。
